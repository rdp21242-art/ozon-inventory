# Мой склад — пересчёт остатков Ozon

Статический сайт для GitHub Pages. Работает в браузере телефона, планшета или компьютера.

## Возможности
- загрузка исходной CSV-выгрузки остатков Ozon;
- распознавание артикула на этикетке камерой (OCR, без штрихкода);
- ручной поиск по артикулу или названию;
- кнопка `+1` для каждой отсканированной единицы;
- пересчёт с нуля: старые остатки не прибавляются;
- при завершении непросканированные товары получают остаток 0;
- экспорт CSV с теми же столбцами и разделителем `;`;
- сохранение текущего сеанса в localStorage браузера.

## Развёртывание на GitHub Pages
1. Открой GitHub и создай новый репозиторий, например `ozon-inventory`.
2. Для простого развёртывания выбери `Public` (GitHub Pages на бесплатном тарифе обычно доступен для публичных репозиториев). Не загружай в репозиторий выгрузки Ozon или другие данные кабинета.
3. Распакуй архив на компьютере.
4. Открой созданный репозиторий → `Add file` → `Upload files`.
5. Загрузи **содержимое папки архива**: `index.html` и `README.md` должны оказаться в корне репозитория, а не во вложенной папке.
6. Нажми `Commit changes`.
7. Открой `Settings` → `Pages`.
8. В блоке `Build and deployment` выбери `Deploy from a branch`.
9. В `Branch` выбери `main`, папку `/ (root)` и нажми `Save`.
10. Подожди завершения публикации и открой адрес вида `https://ТВОЙ-ЛОГИН.github.io/ozon-inventory/`.
11. Добавь сайт на главный экран телефона через меню браузера («На экран Домой» / «Добавить на главный экран»).

## Первый запуск и пересчёт
1. Открой опубликованный сайт.
2. Выбери CSV, выгруженный из кабинета Ozon («Остатки на моих складах»).
3. Разреши браузеру доступ к камере.
4. Наведи заднюю камеру на артикул на этикетке и нажми `Распознать артикул`.
5. Убедись, что программа показала правильный товар, затем нажми `+1`.
6. Повторяй для каждой физической единицы товара. Если нужно, найди товар через ручной поиск.
7. После окончания нажми `Завершить пересчёт и скачать CSV` и подтверди действие.
8. В скачанном файле проверь остатки и загрузи его в кабинет Ozon.

## Важные особенности
- Каждый новый загруженный CSV начинает новый пересчёт с нуля.
- Товар, который ни разу не был отсканирован, получит остаток 0 при экспорте.
- Меняется только столбец `Доступно на моих складах, шт`. Остальные столбцы сохраняются.
- Прогресс хранится локально в браузере конкретного устройства. Он не синхронизируется автоматически между телефоном и компьютером. Для продолжения на другом устройстве потребуется загрузить исходный CSV и начать там новый пересчёт.
- Камера доступна на опубликованном HTTPS-сайте. OCR-модуль и библиотека CSV загружаются из CDN, поэтому для распознавания требуется интернет.
- Перед загрузкой результата в Ozon обязательно проверь скачанный CSV.
